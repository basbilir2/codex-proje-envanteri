# Practical software for printing and small-business workflows

Maintained by [basbilir2](https://github.com/basbilir2). This portfolio collects original software and development experiments for print production, artwork recovery and order/stock/cost management.

## Main projects

| Project | Focus |
| --- | --- |
| [Lenticular Studio](https://github.com/basbilir2/codex-lenticular-studio) | Lenticular print preparation, depth, views and interlacing |
| [Design Recovery / Netleştirme](https://github.com/basbilir2/codex-netlestirme) | Image understanding and artwork reconstruction experiments |
| [DTF Studio](https://github.com/basbilir2/codex-dtf-studio) | DTF artwork and print-layout workflows |
| [Sipariş Takip](https://github.com/basbilir2/codex-siparis-takip) | Order-tracking software |
| [Sipariş Takip VS](projects/codex-siparis-takip-vs/) | Independent order-tracking project |
| [BTakip](https://github.com/basbilir2/codex-btakip) | Stock and business tracking |
| [THesap](projects/codex-thesap/) | Cost and pricing calculations |
| [GeneralVS / agent work](projects/codex-generalvs-calismalari/) | Local development-worker experiments |
| [Local AI OS](projects/codex-local-ai-os/) | Local AI workflow experiments |

## Planned development agent

I plan to develop my own agent to assist these projects with repository-grounded coding, debugging, regression tests, documentation, security review and release preparation. It should make focused changes, report test evidence, respect secrets/customer privacy and require human approval for consequential actions. Future plans also include game prototypes. These goals are a roadmap, not claims of completed features.

## Status and scope

Projects have different maturity levels. See each repository's installation guide and known limitations. Public source availability does not imply that clean installation, live integrations, AI output quality or physical printing have been accepted. No adoption or usage metrics are asserted.

Original contributions are MIT licensed; third-party components retain their own terms. Public copies exclude customer datasets, personal contact details, credentials, private account configuration and private Git history. Fine-tuned weights based on private training data remain in private archives.
