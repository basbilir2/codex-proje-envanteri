# DTF image engine scope
Build a free, reusable image enhancement and print-extraction engine for later integration into the existing Wix app. Preserve artwork identity, letter shapes, ink colours and interior dark fills. No generative redraw or typeset replacement unless separately requested. No Topaz binaries/models, paid image APIs, live Wix changes, credentials, user app changes, or edits outside this project. AMD Ryzen 7 7730U, integrated Radeon (2GB reported), 40GB RAM. Prefer bounded native Vulkan/CPU candidates, not CUDA-only defaults. Use public official open-source engine/model downloads only; record license, source and model used. No broad scans or huge dependency downloads. Keep original immutable. An enlarged image is not proof of new detail. Garment removal must preserve dark ink enclosed by white outlines. Detect uncertainty; never silently claim perfect extraction. No hardcoded Mavi output. Run one actual bounded source-image comparison, save actual transparent PNG and a concise report. If an engine/model is unavailable, report missing dependency rather than a fake fallback. Separate model inference from UI; no new web/desktop interface needed yet. Preserve existing Wix implementation untouched.
DeepSeek coordinates; GLM implements exclusively engine/ and tests/; Nemotron independently reviews without editing. DeepSeek owns README.md, manifests/ and integration/report files. Use actual parallel task calls for GLM and Nemotron. Do not substitute models after errors. Only necessary checks, no repeated successful tests or unnecessary retries.
