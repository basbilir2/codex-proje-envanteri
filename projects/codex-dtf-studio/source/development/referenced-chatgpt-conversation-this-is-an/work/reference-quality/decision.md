# Reference quality and two modes (2026-10-20)

User wants BOTH modes: preserve original design, and AI reconstruction that may reinterpret small details. Preserve current crop -> optional enhancement -> explicit background removal -> approve -> layout order. Existing interface should stay simple. Paid memberships remain out of scope. Earlier zero per-operation cost constraint remains in force unless the pending cost question explicitly changes it.

The supplied reference screenshot includes a dimensional script mavi logo, a clean outlined Mavi/EST1991 design, and a detailed multicolour wolf. Their production method is not known. Reconstruction beyond source information is an inference from their appearance, not a verified provenance claim. Existing app uses ESRGAN Slim2x plus bounded source-fidelity RGB and alpha finishing. It does not implement an image-editing diffusion model.

Research: FLUX.2 klein4B supports reference image editing under Apache2.0; https://github.com/black-forest-labs/flux2 and https://huggingface.co/black-forest-labs/FLUX.2-klein-4B . Official model card discusses approx13GB VRAM; exact hardware depends on precision/offload. This PC reports AMD Radeon integrated graphics with2GB AdapterRAM and about40GB physical RAM. This is NOT a runtime benchmark or proof no CPU/offload route could work. No model weights or paid service have been installed/connected. SUPIR explicitly restricts commercial use without separate written permission: https://github.com/Fanghua-Yu/SUPIR . ResShift likewise S-Lab non-commercial: https://github.com/zsyOAOA/ResShift/blob/journal/LICENSE .

ESRGAN Thick4x (MIT,119MB npm package across all scales) is being benchmarked once on the original Mavi crop using TFJS WASM. This is stronger SR, NOT a real generative redrawing backend and must not be labelled as working reconstruction. Browser docs warn significant latency: https://upscalerjs.com/models/available/upscaling/esrgan-thick/ . Do not publish a fake reconstruction button or claim the reference quality was reached without viewing its real result. No Wix changes made in this research step.
