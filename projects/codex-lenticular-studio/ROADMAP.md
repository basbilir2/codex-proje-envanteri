# Development roadmap

These are planned goals, not implemented or validated features.

1. Document and verify an isolated installation with synthetic inputs.
2. Improve regression coverage around physical dimensions, pitch, channel/view ordering and output metadata.
3. Make depth/animation backend failures and dependency requirements easier to diagnose.
4. Validate reproducible print-preparation examples; record software checks separately from physical results.
5. Develop a repository-grounded maintenance agent: inspect a scoped issue, propose a focused patch, run relevant checks and summarize evidence for human review. No autonomous deployment, spending or customer-data access.

Evaluate API-assisted maintenance by accepted patches, reproducible regressions, documentation completeness and cost per completed task. Broader DTF, tracking-tool and future game prototypes remain separate projects.
