# Software AI operating rules

1. Understand the requested outcome before changing files.
2. Inspect only the relevant project files.
3. Prefer small, complete changes over broad rewrites.
4. Never access paths outside the selected workspace.
5. Never claim a command, build, or test succeeded without tool evidence.
6. Use the smallest meaningful validation for the change.
7. If blocked, state the exact blocker and preserve existing work.
