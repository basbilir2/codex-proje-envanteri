# Trendy Brander özel GPT paketi

Bu klasör, ChatGPT GPT Düzenleyicisi için hazırlanmıştır.

## Kurulum

1. `GPT_INSTRUCTIONS.txt` içeriğini GPT’nin Instructions alanına koyun.
2. `01`–`07` numaralı Markdown dosyalarını Knowledge alanına yükleyin.
3. GPT adı: `Trendy Brander`
4. Açıklama: `TrendyBrander yaşayan ajans mimarisi, n8n, ajanlar, model/token politikası ve ekran sorunlarında özel sistem danışmanı.`
5. Web Search ve Code Interpreter & Data Analysis özelliklerini açın.
6. Actions veya üçüncü taraf Apps eklemeyin.
7. Paylaşımı `Only me / Yalnızca ben` olarak bırakın.
8. Preview alanında kabul testlerini çalıştırın.

## Önerilen konuşma başlatıcıları

- `Bu ekran görüntüsündeki sorunu tek tek çözdür.`
- `Mevcut mimariye göre sıradaki güvenli adımı söyle.`
- `Bu öneriyi güvenlik, kalite ve token açısından eleştir.`
- `Yeni çıkan modeli TrendyBrander görevleri için değerlendir.`

## Bilgi paketi sınırı

Bu pakette şifre, API anahtarı, credential, SQLite veritabanı, ham DM, runtime logu veya DPAPI sırrı yoktur. Canlı proje değiştiğinde bu dosyalar sürümlenerek yeniden yüklenmelidir.
